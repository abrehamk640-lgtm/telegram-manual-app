# Manual Hub - update guide
Upload to the ROOT of your GitHub repo (same paths, replace existing):
  index.html, css/styles.css, js/app.js, data/categories.js, data/products.js, data/promos.js, data/config.js
NEW files to add:
  js/admin.js, css/admin.css
Unchanged: locales/*, img/*
Then in data/config.js set ADMIN_IDS to your Telegram id (get it from @userinfobot).
Admin panel: tap the logo in the header 5 times (or the gear button, shown to admins only).
